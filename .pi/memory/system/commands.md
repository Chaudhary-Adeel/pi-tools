# Project Commands

## Build
```bash
# Build the project
npm run build
```

## Test
```bash
# Run tests
npm test

# Run specific test file
npm test -- path/to/test.ts
```

## Lint
```bash
# Lint the project
npm run lint
```

## Other
```bash
# Type check
npx tsc --noEmit

# Install dependencies
npm install
```
